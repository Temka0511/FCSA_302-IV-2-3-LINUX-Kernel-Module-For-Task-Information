# TaskGraph v1.1.1-bd1

Linux Kernel Module for Listing Tasks — F.CSM302, IV-2-3.

- Тайланд Хавсралт A: төслийн мэдээлэл, зургаан гишүүний үүрэг болон таван туршилтын төлөвлөгөөг нэмэв.

- `for_each_process()` шугаман жагсаалт, `init_task`-аас эхэлсэн шууд
  `children/sibling` DFS. Thread-ээс үүсгэсэн хүүхдийг мөн хамруулна.
- Snapshot-ийн жагсаалтыг `stop_machine()` хамгаална. Сургалтын Linux VM-д
  ашиглана; snapshot авах бүр CPU-ууд түр саатна.
- Linux 6.8.0-31 дээр 17 kernel шалгалт, Python 3.12 дээр 28 тест тэнцсэн.
- Procps-ng 4.0.4-ийн `ps -el`, `ps -eLf` гаралт болон task бүрийн
  харьцуулсан нотолгоо `docs/evidence/` хавтсанд бий.
- Шинэчилсэн тайлан, хэрэглэгчийн болон ажиллагааны гарын авлага хавсаргав.

Ubuntu дээр clone хийсний дараа README-ийн суулгах, ажиллуулах зааврыг дагана.
Хуучин модуль ажиллаж байгаа бол UI-г хааж, модулийг буулгаад шинэ кодыг
хөрвүүлж дахин ачаална.
