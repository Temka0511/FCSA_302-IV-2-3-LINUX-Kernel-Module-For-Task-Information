# TaskGraph v1.1.6-bd1

Linux Kernel Module for Listing Tasks — F.CSM302, IV-2-3.

- `/proc/taskgraph`-ийн давтан ба зэрэгцсэн нээлтийг mutex, reference count,
  400 ms immutable cache-аар хязгаарлав. Хэт ойр нээлтүүд CPU-г дахин дахин
  зогсоохгүй; UI-ийн 500 ms шинэчлэлт хэвийн ажиллана. QEMU-ийн K18 тестээр
  ижил агшин ба хугацаа дууссаны дараах шинэ хэмжилтийг шалгав (18/18).
- LINEAR графын одоогийн `draw()` кодоос үүсгэсэн parent сумны вектор схемийг
  тайланд нэмэв; хуучин DFS screenshot-ийн огноо, хамрах хүрээг тодруулав.
- Сонгосон зангилааны хүрээг T/D-ийн улбар шар өнгөнөөс нил ягаанаар ялгаж,
  Secure Boot-ийн гарын үсэг хавсаргах алхмыг модуль дээр туршив.

- Бие даасан шалгалтаар CLI-ийн LINEAR горимын баганын нэр ба rank буруу
  тайлбарлагдаж байсныг засав. LINEAR графын бодит parent сум, харагдах
  дарааллыг шалгах хоёр regression тест нэмэв (30/30).
- README болон тайлангийн T төлөвийн өнгөний тайлбарыг бодит улбар шар өнгөтэй
  тааруулав. Шинэ шалгалтын log, JSON: `docs/evidence/recheck-v1.1.6/`.

- V-1-14 багийн шүүмжийн дагуу LINEAR горимын графын холбоосыг DFS байрлалтай,
  зангилааны хоорондын чөлөөтэй зурвасаар гаргахаар засав. LINEAR хүснэгт ба
  алхамчилсан үзүүлэлт тус тусын дарааллыг хадгална.
- Manual PDF-ээс clone командыг шууд хуулж ажиллуулах боломжтой болгож URL-ийг
  богино мөрүүдэд хуваав; Secure Boot/MOK гарын үсгийн алхмыг нэмэв.
- Буруу max_tasks-ийн шалтгааныг kernel log-д хэвлэж, өнгөний тайлбар болон
  LINEAR зангилааны шошгыг засав. /proc/taskgraph-ийн 0444 эрх ба stop_machine()
  ашиглалтын хязгаарлалтыг ил тод баримтжуулав.

- Архитектур, snapshot унших дараалал, бодит 7 task-ийн мод гэсэн гурван вектор схем нэмэв.
- Онол, зохиомжийн тайлбарыг дэлгэрүүлж, цөм ба хэрэглэгчийн орон зай, PPID/TGID,
  шинэ хэмжилт болон snapshot-ийн шүүлтийн ялгааг тайлбарлав.
- Гарчиг, зургийн тайлбар, схем, хүснэгтийн хөх өнгийг жигд болгов.
- Тайлангийн үндсэн хүснэгтүүдэд бүрэн хүрээ, мөр тусгаарлалт, нүдний зай болон өнгөөр ялгасан гарчиг оруулав.
- Тайланд Хавсралт A: төслийн мэдээлэл, зургаан гишүүний үүрэг болон таван туршилтын төлөвлөгөөг нэмэв.

- `for_each_process()` шугаман жагсаалт, `init_task`-аас эхэлсэн шууд
  `children/sibling` DFS. Thread-ээс үүсгэсэн хүүхдийг мөн хамруулна.
- Snapshot-ийн жагсаалтыг `stop_machine()` хамгаална. Сургалтын Linux VM-д
  ашиглана; snapshot авах бүр CPU-ууд түр саатна.
- Linux 6.8.0-31 дээр 18 kernel шалгалт, Python 3.12 дээр 30 тест тэнцсэн.
- Procps-ng 4.0.4-ийн `ps -el`, `ps -eLf` гаралт болон task бүрийн
  харьцуулсан нотолгоо `docs/evidence/` хавтсанд бий.
- Шинэчилсэн тайлан, хэрэглэгчийн болон ажиллагааны гарын авлага хавсаргав.

Ubuntu дээр clone хийсний дараа README-ийн суулгах, ажиллуулах зааврыг дагана.
Хуучин модуль ажиллаж байгаа бол UI-г хааж, модулийг буулгаад шинэ кодыг
хөрвүүлж дахин ачаална.
